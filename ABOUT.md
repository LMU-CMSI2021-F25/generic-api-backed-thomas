## About this App

This app is an NBA Data Website. In it, you will find three things: a player lookup, a game lookup, and a team lookup. By entering information, you can find the data you are searching for. All data is sourced from the BallDontLie API, with additional information being able to be found from other sources. These are not apart of the API, and link to external websites, as the API does not supply all the information that could be displayed (in order to do this I would need to pay).
